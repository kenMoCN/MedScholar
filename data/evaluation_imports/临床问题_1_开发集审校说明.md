# 《临床问题(1)》开发集审校说明

审校日期：2026-10-05

## 数据集定位

- 原文共 18 道题，其中低钾血症题重复一次；合并后为 17 道独立题。
- 本数据集只用于开发、调试和错误分析，不属于正式盲测集。
- 文档中的“我认为的答案”保存为 `student_answer`，不作为金标准。
- `provisional_reference_answer` 是 AI 初审后的暂定参考答案，仍需生理学教师或相应专科临床教师确认。

## 初审结果

- 9 道题的原答案基本正确，主要需要补充限定条件或改进表述。
- 8 道题需要实质性修订：COPD 控制氧疗、心肌动作电位与心律失常、感染性与心源性休克鉴别、感染性休克糖皮质激素、倾倒综合征、运动性肌肉疲劳、心源性与过敏性休克治疗、FEV1/FVC 解读。
- 高风险题不只评估“能否答出”，还要评估智能体是否会纠正题干或学生答案中的过度概括。

## 评测使用原则

1. 课程机制题应优先回归《生理学（第五版）》并给出可追溯依据。
2. 涉及当前诊断阈值、用药或抢救原则时，应使用最新官方指南，不能只凭教材或模型记忆。
3. 回答必须区分生理机制解释与个体化临床处置，后者应提示适用条件。
4. 暂定答案经教师确认后，才可升级为正式 `gold_answer`。

## 教材检索诊断

- 初次 Top-3 检索：15 道具有教材来源标注的题中命中 11 道，命中率 73.3%。
- 失败原因不是教材文件缺失，而是长临床题干使关键短语的匹配分数被大量上下文稀释，同时 PDF 中的全角英文缩写无法与普通 ASCII 查询稳定匹配。
- 修正长题干局部关键短语计分并增加 Unicode NFKC 归一化后，15/15 道均在 Top-3 命中声明的教材来源，开发集检索命中率为 100%。
- 该结果仅表示命中了正确教材，不代表命中了足以支持全部临床结论的具体页，也不代表端到端答案正确。

## 首轮端到端基线（关闭 Skill）

- 17 道题中发布答案 5 道，因证据不足进入人工复核 12 道。
- 预期流程结果一致率为 29.4%；严格通过为 0/17。
- 教材来源级命中率为 100%，已发布答案的逐字引文与语义支持核验率为 100%。
- 平均关键概念覆盖率为 35.2%。当前术语评分对同义表达仍偏严格，因此该数值只能用于逐题诊断，不能直接解释为医学正确率。
- 基线暴露出“证据真实但未回答题目核心”的漏洞：失血题发布的答案重点解释了化学感受性反射，而题目明确要求压力感受性反射。现已在独立语义核验中增加 `__question_coverage__` 检查，要求答案覆盖核心对象、指定机制和全部子问。
- 多数拦截并非程序错误，而是现有教材证据无法直接支持题目中的临床诊断、用药或教材外机制。下一阶段应扩展可发布的外部证据来源，并设计“已支持部分先回答、未支持部分明确保留”的分段答复机制。

## 基线后的架构修正

- 新增 `answerability=partial`：有证据的部分可以先发布，缺证据的子问必须写入 `unanswered_aspects`，同时继续运行外部补证。
- 允许将多条教材前提连接成保守的机制推论，但必须标记为不确定推论、绑定全部前提证据，且不得外推诊断、用药、剂量或治疗建议。
- 题意覆盖核验能够识别完整回答与部分回答：部分回答只要切中至少一个实质性核心任务，并清楚列出未回答子问，即可通过覆盖检查。
- 正文证据核验与完整性核验已分离，避免因为部分回答主动声明缺口而被重复处罚。
- 右心衰竭题真实复测已由 `review_required` 改为 `completed + partial`，语义核验通过，并继续返回外部候选资料。
- 呈现层自动隐藏高度重复的解释段，guided 模式思考题最多显示2条；部分回答不再重复展示“局限”和“待核实”。

## 已核对的时效性来源

- GOLD 2026：COPD 诊断应结合临床背景并使用支气管舒张后 FEV1/FVC；固定 0.70 阈值存在年龄相关误分风险。
- Surviving Sepsis Campaign：成人感染性休克持续需要升压药时，才考虑静脉糖皮质激素，而不是所有感染性休克常规使用。
- World Allergy Organization：肌内肾上腺素是过敏性休克的一线用药，糖皮质激素不能替代。

## 回答质量改造复测

- Plan 阶段现同时使用模型生成的教材同义检索词与确定性拆题兜底；Execute 阶段实际执行最多4条子检索，并为各子问保留证据页，不再只检索一次完整长题干。
- 独立核验增加题意覆盖检查，防止“引用正确但答非所问”；修订器会删除未获支持的主张，把仍缺证据的核心子问转入部分回答，而不是拦截整题。
- 为避免核验模型转抄教材时产生伪逐字引文，程序先把教材原文切成不可修改的编号片段；核验模型选择片段编号，最终引文使用编号对应的真实原文。
- 17题复测中，预期流程结果一致率由29.4%提高到82.4%，平均关键概念覆盖率由35.2%提高到40.6%；检索命中率和已发布答案引用核验率保持100%。
- 严格通过仍为0/17，主要因为多数答案没有覆盖开发题中声明的全部预期术语，且暂定参考答案尚未经过教师确认。本轮指标只用于开发诊断，不能称为正式医学准确率。
- 复测后又单独修正并验证低钾血症题：它由核验引文格式导致的整题拦截，改为正常发布有教材依据的机制回答，并明确列出仍需直接证据支持的临床联系。该单题修复尚未重跑全部17题，不能据此改写整套复测指标。

## 2026-10-06 核心稳定性修正

- Plan 阶段已明确分离“用于找资料的检索词”和“最终必须回答的用户要求”。教材同义词只扩大召回，不再被误当作新增子问；题干中“从……角度”“结合……解释”等明确要求则保留为答案契约。
- 模型生成的内部主张如果没有出现在最终正文中，不再因为其自身核验失败而误伤一份正文已经完整获证据支持的答案；正文、解释和教学提问仍须分别通过语义支持检查。
- 对明确承认缺口的部分回答，只要已经回答的正文有证据支持，并且用户明确要求的每个方面都被回答或列入待核实项，即可发布，不再要求教学提问覆盖尚未回答的部分。
- 术语层增加“兴奋-收缩偶联/耦联”等常见写法归一化；同时保留独立语义核验，避免只靠关键词判分。
- 模型偶发返回截断或非 JSON 内容时，适配器会在限定次数内要求其重新返回一个完整 JSON 对象；证据核验未通过时，端到端流程最多进行两轮有针对性的修订。
- 最新一次完整 17 题开发集运行记录为：预期流程结果一致 13/17（76.5%），教材来源级检索命中率 100%，已发布答案引用核验率 100%。其中 3 题因语义核验波动进入人工复核，1 题因模型返回非法 JSON 失败；该次运行发生在新增 JSON 重试和第二轮修订之前。
- 新增稳定性措施后，止血题已由 JSON 失败恢复为 `completed`；低钾血症题也再次得到 `completed` 且引用核验通过。低钾题的关键词覆盖显示 50%，原因是当前开发评分器要求“细胞外K+降低”等固定连续字串，而实际答案使用“细胞外K+浓度降低”“与阈电位的距离增大”；因此关键词覆盖率不能替代人工医学审校或语义评估。
- 运动疲劳题的本轮单题调用在模型返回前异常退出，未产生报告，不能据此宣称已经通过；此前的定向复测曾通过，但仍需后续在稳定网络/模型服务下复核。
