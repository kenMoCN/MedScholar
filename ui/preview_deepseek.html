# 一、微循环改变的主要特点 在休克早期（缺血性缺氧期），机体微循环的最核心血流动力学特征是：**少灌少流，灌少于流**。 | 结构部位 | 状态改变 | 血流动力学影响 | | :--- | :--- | :--- | | **微动脉与后微动脉** | 强烈痉挛性收缩 | **前阻力显著升高**，毛细血管前括约肌收缩 | | **真毛细血管网** | 大部分处于关闭状态 | 组织灌流量骤减，毛细血管内静水压降低 | | **动-静脉短路** | 反射性开放 | 血液绕过毛细血管床，直接回流进入微静脉 | | **微静脉** | 轻中度收缩 | **前阻力 > 后阻力**，有效减少血管容积 | --- # 二、发生机制（神经-体液调节） 此期的血管强烈收缩主要由**交感-肾上腺髓质系统极度兴奋**驱动： 1. **儿茶酚胺大量释放**：交感神经末梢释放去甲肾上腺素，肾上腺髓质释放肾上腺素，强烈兴奋微血管上的 $\alpha$ 受体。 2. **肾素-血管紧张素-醛固酮系统 (RAAS) 激活**：肾血管强烈收缩引起血管紧张素 II 释放，产生强效全身小动脉收缩。 3. **其他体液因子参与**：血管升压素 (VP/ADH) 及内皮素 (ET) 合成与释放增多，加剧微血管痉挛。 > **人卫教材考点速记**：毛细血管前阻力血管对儿茶酚胺的敏感性**显著高于**后阻力血管（微静脉），因此产生“前阻力增加大于后阻力增加”，毛细血管滤出减少，组织液向毛细血管内转移。 --- # 三、代偿意义 该阶段是机体的自我保护性应激反应，又称**代偿期休克**： - **“自身输血”**：微静脉收缩使肝、脾、腹腔等储血库血液快速回流，增加有效循环血量。 - **“自身输液”**：毛细血管前阻力大于后阻力使毛细血管内流体静压下降，组织液快速渗入血管补充血容量。 - **“血液重新分布”**：皮肤、腹腔内脏及骨骼肌血管强烈痉挛收缩，血液优先供应生命中枢（**脑血管与冠状动脉血管**收缩不明显），保障脑与心肌的基本灌注。
